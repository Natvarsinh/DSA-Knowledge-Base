# When to use
- After solving a problem
- To generate clean problem.md

# Prompt
Generate a structured problem.md for:

<PROBLEM NAME + DESCRIPTION>

Include:

1. Problem statement
2. Example input/output
3. Pattern used
4. Clues to identify pattern
5. Approach 1 (brute force)
6. Approach 2 (optimized)
7. Key learning
8. Edge cases
9. Mistakes to avoid

Keep it clean and GitHub-friendly.
